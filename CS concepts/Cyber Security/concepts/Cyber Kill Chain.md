1. cyber kill chain
- part of Intelligence Driven Defense model for identification and prevention of cyber intrusions activity
- identifies what adversaries must complete to achieve their objective
- steps
   - reconnaissance
      - harvesting email address
      - conference information
   - weaponization
      - create malware to exploit vulnerability
   - delivery
   - exploitation
      - move laterally
      - find sensitive data, additional vulnerabilities, admin accounts, etc
   - installation
      - install malware on system
   - command & control
      - create control center for remote operation
      - use obfuscation to cover tracks
   - actions on objectives
      - take steps to achieve primary goal
