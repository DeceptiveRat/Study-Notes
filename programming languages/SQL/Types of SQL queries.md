# 1. Select
- The most common type of SQL query^(1)^
- Lets you retrieve a single row or a group of rows from a table. You can retrieve data in alphabetical order, by column or by any combination of columns^(1)^
- Can also be used to create a query that returns a specific type of data or a specific number of columns^(1)^

# 2. Insert
- Used to add new data to a table^(1)^
- Can be used to insert a single row, a group of rows or multiple rows at once^(1)^

# 3. Update
- Used to change the data in the table^(1)^
- Update a single row, a group of rows or multiple rows at once^(1)^

# 4. Delete
- Used to delete data from a table^(1)^
- Delete a single row, a group of rows or multiple rows at once^(1)^
