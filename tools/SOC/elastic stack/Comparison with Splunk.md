1. Splunk
- proprietary security and observability platform
- index machine data 
- search, analyze, and visualize data

2. comparison with ELK stack 
- ELK stack is open source => can use for free
- Splunk is proprietary => need to pay to use
- ELK stack has a distributed architecture => difficult to set up
- Splunk just requires a server => easier to set up

| criteria | ELK stack | Splunk |
| --- | --- | --- |
| Price | Cheap or free | More expensive |
| Setup | More difficult | Eaiser |
