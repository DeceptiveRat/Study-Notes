1. dimensionality reduction
- reduces number of input to manageable size
- preserves integrity as much as possible

2. dimensionality reduction methods
- principal component analysis
   - reduces redundancies and compresses datasets through feature extraction
   - used linear transformation to create a new data representation
- singular value decomposition (SVD)
   - factorized a matrix A into three, low-rank matrices
   - formula: A = USVT
   - used to reduce noise and compress data
- autoencoders
   - leverages neural networks to compress data and create new representation of original input
