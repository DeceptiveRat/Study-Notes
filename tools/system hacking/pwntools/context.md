the context object is a global, thread-aware object which contains various settings used by pwntools

settings:
- arch
   - aarch64
   - arm
   - i386 (default)
   - amd64
- bits
- binary
- endian
- log_file
- log_level
   - debug
   - info
   - error
- sign
- terminal
- timeout
- update
set multiple values at once
