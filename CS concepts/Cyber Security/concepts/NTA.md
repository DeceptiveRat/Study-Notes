1. Network Traffic Analysis (NTA)
- process of collecting and analyzing data from computer networks
- helps organizations optimize network performance, mitigate security threats, and troubleshoot problems

2. NTA steps
- data collection:
   - data capture focuses on raw data flowing across network
   - relies on specialized tools like network analyzers, packet sniffers, and IDS
- processing:
   - necessary to transform raw data into actionable data that's easier to analyze
- analysis:
   - behavioral analysis
   - protocol analysis
   - statistical analysis
   - payload analysis
   - flow analysis
- data visualization:
   - usually involves dashboards, graphs, charts, etc

3. NTA analysis - behavioral analysis
- focuses on patterns
- relies on baseline models to identify suspicious activities
- advanced behavioral analysis tools use ML 

4. NTA analysis - protocol analysis
- protocols provide important clues

5. NTA analysis - statistical analysis
- looks at network traffic volume and traffic patterns
- uses mathematical formulas on network metrics like volume, packet size, and protocol distribution
- estimates likelihood of cyberthreat or network issue

6. NTA analysis - payload analysis
- examines application-layer information 
- helps gain insight into communication occuring

7. NTA analysis - flow analysis
- looks for evidence of troubling patterns
- helps resolve security incidents and spot potential bottlenecks

8. NTA benefits
- insight into traffic patterns:
   - uncovers traffic patterns
   - helps optimize network performance and identify bottlenecks
- automated anomaly detection:
   - ML tools increase operational visibility
- increased utilization awareness:
   - can view network volume and distribute workloads for efficiency
- enhanced security and troubleshooting:
   - helps admins spot sudden changes in network conditions
   - AI tools speed up process of traffic classification and incident tracking
- improved bandwidth management
- more diverse data sources:
   - helps diversify monitored data
- integration with other systems

9. NTA use cases
- detecting traffic from anomalous locations
- prevent DNS tunneling:
   - ensures DNS queries and responses only contain legitimate traffic
- identify suspicious devices:
   - can track activity from all authorized network devices
- monitor threats in real-time
- comply with relevant policies and regulations
