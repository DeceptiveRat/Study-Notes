# 1. DNS
## (1) enumeration
- the most important records to look for in DNS enumeration are:
- A (address) records containing the IP address of the domain
- MX records, which stands for Mail Exchange, contain the mail exchange servers
- CNAME records use for aliasing domains. Stands for Canonical Name. Links any subdomains with existing domain DNS records
- NS records, which stands for Name Server, indicates the authoritative name server for the domain
- SOA records, which stands for State of Authority, contain important info about the domain, such as the primary name server, a timestamp showing when the domain was last updated and the party responsible for the domain
- PTR records map an IPv4 address to the CNAME on the host
- TXT records contain text inserted by the admins
