1. Security Operating Center
- team of IT security professionals dedicated to monitoring the IT infrastructure 
- detect, analyze, and respond to security incidents in real-time
- consists of:
   - tier 1 analyst: filter false positives and escalate to tier 2 analysts
   - tier 2 analyst: understand scope of attack and affected systems
   - tier 3 analyst: neutralize advanced threats
   - SOC manager: supervise the analysts and coordinate plans

2. tools used
- security information and event management (SIEM)
   - log management
   - real-time monitoring
   - Incident Response (IR)
   - visualization/report
- Network Security Monitoring (NSM)
- Intrusion Detection and Prevention System (IDS/IPS)
   - generate alerts
   - block threats
   - log and report
- Endpoint Detection and Response (EDR)
   - real-time monitoring
   - User Entity Behavior Analytics (UEBA)
   - incident investigation
- firewalls
- forensic analysis tools
   - data acquisition
   - file system analysis
   - memory forensics
   - registry forensics
   - network traffic forensics
- malware analysis tools
   - dynamic analysis
   - static analysis
   - behavioral analysis
   - signature/pattern matching
