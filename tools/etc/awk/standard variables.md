1. argc
- argument coun

2. argv
- argument array

3. CONVFMT
- conversion format for numbers

4. ENVIRON
- associative array of environment variables

5. FILENAME
- current file name

6. FS
- file separator

7. NF
- number of fields in current record

8. NR
- number of the current record

9. FNR
- NR, but relative to current file

10. OFMT
- output format number

11. OFS
- output field separator

12. ORS
- output record separator

13. RLENGTH
- length of the string matched by match function

14. RS
- input record separator

15. RSTART
- first position in string matched by match function

16. SUBSEP
- separator character for array subscripts

17. $0
- entire line record

18. $n
- nth field in the current record
- fields are separated by FS
