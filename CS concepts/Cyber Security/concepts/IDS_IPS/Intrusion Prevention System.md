1. Intrusion Prevention System (IPS)
- monitors network traffic
- blocks potential threats and alerts security team
- supports regulatory compliance efforts

2. IPS detection methods
- signature-based
- anomaly-based
- policy-based:
   - based on security policies set by security team
   - offer customization
   - requires significant upfront investment
- reputation-based
- stateful protocol analysis

3. IPS types
- Network-based IPS (NIPS)
- Host-based IPS (HIPS)
- Network Behavior Analysis (NBA):
   - monitors network traffic flows
   - focus on higher-level details of communication sessions (e.g. source/destination IP/port, number of packets)
   - uses anomaly-based detection
- Wireless IPS (WIPS):
   - monitors wireless network protocols
   - can also help detect misconfigured/unsecured devices on wifi network
   - can intercept man-in-the-middle attacks
