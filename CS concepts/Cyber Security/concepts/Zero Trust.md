1. zero trust
- no one is trusted by default; verification is required

2. main principles
- continuous monitoring and validation
   - verify user identity/privileges
   - verify device identity and security
   - logins/connections periodically time out forcing revalidation
- least privilege
   - involves careful managing of permissions
- device access control
   - strict controls on device access
   - assess devices for compromise
- microsegmentation
   - break up security perimeters into small zones
   - separate access for separate parts of network
- preventing lateral movement
- Multi-factor Authentication(MFA)
