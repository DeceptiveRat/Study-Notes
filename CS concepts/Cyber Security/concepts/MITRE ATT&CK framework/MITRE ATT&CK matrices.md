### 1. enterprise matrix
adversary techniques used in attacks against enterprise infrastructure. Includes submatrices for Windows, MacOS, Linux, network infrastructure and cloud platforms. Also includes a PRE matrix of preparatory techniques used in advance of an attack

### 2. mobile matrix
techniques used in direct attacks on mobile devices, and in network-based mobile attacks. Submatrices include iOS and Android

### 3. ICS matrix
techniques used in attacks on industrial control systems, specifically machinery, devices, sensors and networks used in factories, transportation systems, etc
