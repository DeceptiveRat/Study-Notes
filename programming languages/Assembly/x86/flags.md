## 1. status flag
- sign flag (SF)
1 if MSB of a result is 1
- zero flag (ZF)
1 for zero result
- carry flag (CF)
1 if there is a carry out from the MSB on addition or borrow into MSB on subtraction
- auxiliary carry flag (AF)
1 if there is a carry out from bit 3 on addition or borrow into bit 3 on subtraction
- parity flag (PF)
1 if low byte of result has an even number
- overflow flag (OF)
1 if signed overflow occurred
