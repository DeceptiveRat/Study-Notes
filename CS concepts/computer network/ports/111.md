# 1. rpcbind
rpcbind is a server that converts RPC program numbers into universal addresses^(1)^

## • Enumeration
### (1) connect^(2)^
nc -z -v -u <target ip> 111

### (2) Recon^(2)^
rpcinfo -p <target ip>
once connected, rpcinfo can be used to learn the details on it

### (3) Enumeration^(2)^
rpcenum -v <target ip>
the rpcenum script can be run to collect information

the -v flag gives more details

## • rpcbind + NFS
If you find the service NFS, you will probably be able to list and download, maybe even upload, files^(3)^
(view NFS for more)
