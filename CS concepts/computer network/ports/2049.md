# 1. NFS 
The Network File System is a distributed file system protocol that allows a client to access files over a network as if those files were on the client's local file system^(1)^

## • enumeration
### (1) showmount^(1)^
- can be used to fetch a list of remote file systems which are exported by the target

- showmount -e <target ip>
e: display the list of remote file systems on the NFS server

- mkdir /tmp/mount && mount <target ip>:home/karl /tmp/mount
create a directory mount and mount the remote directory
