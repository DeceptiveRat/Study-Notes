## 1) Running DLLs
### 1.1) rundll32.exe
provides a container for running a DLL

```plain-text
rundll32.exe DLLname, Export arguments
```

- Export argument: exported function name or ordinal

### 1.2) modify PE header
wipe IMAGE_FILE_DIR (0x2000) flag from the Characteristics field in the IMAGE_FILE_HEADER

### 1.3) InstallService
DLL malware may need to be installed as a service
