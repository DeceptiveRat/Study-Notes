1. degree of freedom
- N values in population => df = N
- N values in sample => last data is constrained, df = N - 1
- e.g.
mean of 3 numbers is 10, two numbers are 5 and 15
=> last number must be 10

2. level of significance
- predetermined level at which null hypothesis is not supported
- commonly  p < 0.5
- if critical value <= 0.5 H~0~ is rejected
- if critical value > 0.5 H~0~ is not rejected
