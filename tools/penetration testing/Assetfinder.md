# 1. installation
- google assetfinder
- open the github for assetfinder by tomnomnom
- use go to install assetfinder
go get -u github.com/tomnomnom/assetfinder

# 2. usage
- assetfinder <website name>
finds all subdomains related to or possibly owned by the website

- assetfinder <website name> --subs-only
only gets the subdomain
