1. Lightweight Directory Access Protocol (LDAP)
- industry standard application protocol for accessing and maintaining distributed directory information services over IP
- all information is transmitted using Basic Encoding Rules (BER)

2. LDAP steps
- client connects to LDAP server
- client sends operation request 
- server responds

3. ports used
- LDAP: TCP/UDP port 389
- LDAPS: TCP/UDP port 636
