1. variables
- use _ by default
- e.g.
	- *output_file_ptr*
	- *connection_handler*

2. functions
- use CamelCase by default
- e.g.
	- *printToFile*
	- *isNumber*

3. structures
- use _ by default
- in uppercase to distinguish from variables
- e.g.
	- *ALLOCATED_POINTERS*

4. macros
- uppercase with _ as space
- e.g.
	- *BUFFER_SIZE*
